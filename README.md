# 🎮 2D Action-Adventure Game / 2D darbības un piedzīvojumu spēle

## 🌟 About the Game / Par spēli
**EN:**  
This is a 2D action-adventure game developed in Godot for a qualification project.  
The game is inspired by classic platformers and modern action-adventure titles, combining fast-paced gameplay with strategic challenges.  

**LV:**  
Tā ir 2D darbības un piedzīvojumu spēle, kas izstrādāta Godot vidē kā kvalifikācijas darbs.  
Spēle ir iedvesmota no klasiskām platformeru spēlēm un mūsdienu darbības–piedzīvojumu projektiem, apvienojot dinamisku spēli ar stratēģiskiem izaicinājumiem.  

---

## 🕹️ Gameplay / Spēles process
**EN:**  
Players control a character navigating through various levels filled with obstacles ⚔️ and enemies 👾.  
The goal is to reach the end of each level while using skills and strategy to overcome challenges.  

**LV:**  
Spēlētājs vada varoni, kurš pārvietojas pa dažādiem līmeņiem ar šķēršļiem ⚔️ un ienaidniekiem 👾.  
Mērķis ir sasniegt katra līmeņa beigas, izmantojot prasmes un stratēģiju, lai pārvarētu visus izaicinājumus.  

---

## 🎯 Objective / Mērķis
**EN:**  
Complete all levels, master the game mechanics, and progress through increasingly difficult stages.  

**LV:**  
Pabeigt visus līmeņus, apgūt spēles mehānikas un virzīties uz priekšu pa arvien grūtākiem posmiem.  

---

## ✨ Inspiration / Iedvesma
**EN:**  
The game draws inspiration from classic 2D platformers and adventure games, emphasizing both skill and planning in gameplay.  

**LV:**  
Spēle ir iedvesmota no klasiskām 2D platformeru un piedzīvojumu spēlēm, uzsverot gan spēlētāja prasmes, gan iepriekšēju plānošanu.  

---

## 🚀 Features / Galvenās iespējas
**EN:**
- Multiple challenging levels 🏰  
- Obstacles and enemies to overcome ⚡  
- Engaging and precise controls 🎮  
- Strategic gameplay that rewards planning 🧠  

**LV:**
- Vairāki izaicinoši līmeņi 🏰  
- Šķēršļi un ienaidnieki, kas jāpārvar ⚡  
- Precīva un patīkama vadība 🎮
